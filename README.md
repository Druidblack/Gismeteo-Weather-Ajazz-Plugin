# Gismeteo-Weather-Ajazz-Plugin
Плагин для отображение погоды с сайта Gismeteo

# Как установить
Скачайте релиз и распакуйте папку по пути
````
C:\Users\USERNAME\AppData\Roaming\HotSpot\StreamDock\plugins
````

## Настройки города

Можно использовать **любой один** из следующих способов:

- **Название города**: `Москва`, `Берлин`, `Казань`. Это поле одновременно используется как подпись.
- **Ссылка на Gismeteo** (в поле «ID, ссылка Gismeteo или название»): `https://www.gismeteo.ru/weather-moscow-4368/`.
- **ID Gismeteo**: `4368` (Москва).
- **Координаты**: широта + долгота (например, `55.7558` / `37.6173`).

Приоритет: **ID/ссылка → координаты → название**. Если в поле ID написано только название, оно тоже будет использовано для поиска. Можно указать название как подпись, а ID как источник.

## Действия

1. «Текущая погода» — иконка, температура, название.
2. «Показатель погоды» — выбираемый показатель: температура, по ощущениям, влажность, давление, скорость/направление ветра, облачность, осадки, магнитная активность, восход, закат, температура воды.
3. «Прогноз погоды» — температуры и состояние погоды для выбранного дня (до 7 дней при наличии данных).
